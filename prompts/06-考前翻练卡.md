# 剧本 06 · 考前翻练卡(可选但强烈建议)

**用途**: 生成"题 → 翻哪块"的定位自测,解决实战最大痛点 —— 内容全但考场找得慢。
**时机**: 小抄定稿、打印之前或之后一天。
**输入**: 小抄全稿 + 考点地图。
**产物**: `翻练卡.md`(20~30 道题,每题标答案在第几块)。
**用法**: 考前 30 分钟不看小抄内容,只看题,抢答"这题在哪个块"——答不出就快速定位
并记住位置。重复 2~3 轮直到 90% 以上秒答。考场上是"看到题→翻块→誊抄",不是现场找。

---

## 给 AI 的提示词

你是考前陪练。用户有一份分块的小抄(每块以【数字·主题】开头),请你出 25 道
"定位自测题",规则:
- 每道题 = 一句模拟考题(覆盖定义/机制/公式/数字/对比/易错点六类,均匀分布);
- 给出答案所在块号与一句话提示(≤15字),不要把答案全文写出来;
- 答案涉及多个块的要标"主块+次块";
- 同时把课件里最容易设坑的 5 个易错点单独列为"易错点名",每题标对应块。

输出格式:
```
01. (定义) 什么是困惑度?  → 块11 公式块·指标
...
易错点名:
- LLaMA 参数量两处写法不一致,课件 p.89 写作 630 亿,与 652 亿矛盾,疑笔误 → 块01
```
