# 剧本 02 · 图片页与公式页视觉转录

**用途**: 把文字层抓不到的图页/公式页(analyze_pdf.py 判定的低密度页 + 人工抽翻补充页)
转录成文本,补回课件知识库。**跳过这一步 = 静默丢分**,公式常以图片对象存在,
文字层里一个字都没有。
**时机**: render_pages.py 渲染出 PNG 之后。
**输入**: PNG 图片(一次一批,10~20 张为宜)。
**产物**: `图页转录.md`(逐页转录,公式用纯文本数学记号),并入复习底稿。
**质量门**: 每个图页都有转录结果;公式符号一个不漏(上标下标、求和号、希腊字母都显式写出)。

---

## 给 AI 的提示词(复制以下内容;每批图片发一次)

我将分批发给你一些 PPT 截图/PDF 渲染页(来自课程课件,多是公式页、示意图页、
表格页——这些内容在 PDF 文字层中不存在,只有图片)。请你对**每一张图**输出:

```
【图页码 p00X】(用文件名里的页码)
类型: 公式页 / 概念图 / 流程图 / 表格 / 照片
内容转录:
- 如果含公式: 用纯文本严格转写,例: loss = -Σ(y·log ŷ);上标用 ^(如 2^n)、
  下标用 _(如 W_q)、求和用 Σ(注明上下限)、希腊字母写中文名+字母(如 伽马 γ);
  矩阵/向量用方括号排版;逐项列出,不要"类似/省略";
- 如果含表格: 转成 Markdown 表格,单元格内容不缩写;
- 如果是概念/流程图: 描述结构(方框/箭头关系/分支条件),并把图中所有文字
  (标题、标注、轴标签、图例)逐字列出;
- 如果含数字结论(如模型参数量、评估得分): 原样保留数字与单位。
要点:
- 看不清的地方老实说"此处看不清",不要编造;我会补发高清图;
- 同一批图处理完,汇总成一个 markdown 文件内容,按页码排序;
- 如果图里有前后矛盾的数据(比如两个表同一模型的参数量不一致),单独列一条"数据冲突提醒"。
```

---

## 附录 · 图特别多的课件:先"快速筛选"再正式转录

analyze_pdf.py 提示"含图候选页偏多"时用这个工作流,能砍掉大半转录量:

**第一轮 · 快速筛选(每批 15~20 张图,轻量回答)**

```
这批图来自课程课件(渲染页)。请只做一件事:逐张判断"这张图里是否包含
文字层没有的信息"——即图的标题/标注/数据/结构无法从课件正文文字推断。
对每张图只输出一行: 【p00X】有信息 / 无信息(1~3字理由)。
没有信息的直接跳过,不要展开描述。
```

**第二轮**: 把"有信息"的图再按本文件正式转录提示词处理。筛掉的图通常占一半以上。

**工作量预期**: 渲染一张 PNG 约 1 秒;快速筛选一轮约 18 批 × 1~2 分钟;
正式转录只针对命中页。全程比人工翻 PDF 快且不会漏。

---

## 备注

- **人工抽翻复核**: 低密度页是"候选",不代表全部。强烈建议把 PDF 整体快速翻一遍
  (每页停留 1 秒),凡"看起来有图/有大段公式/有表格而文字层没对应内容"的页,
  用 render_pages.py --pages 补渲染再转录。677 页课件实战中,图片页约 88 页,
  其中约 1/4 不在低密度清单里(文字层有标题但图是核心内容)。
- **数据冲突要重视**: 转录时发现的"同物不同数"往往就是课件笔误,也是考试爱挖的坑
  (实战案例:某模型参数量课件里出现 652 亿/65.2B/630 亿三种写法)。剧本 05 会系统查。
- 转录产出与剧本 01 的章节文本合并,就构成"完整课件知识库",后续剧本都基于它。
